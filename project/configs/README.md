# Конфигурационные файлы

Все настраиваемые параметры проекта вынесены сюда — менять поведение можно без правки кода.

- `config.yaml` — общие настройки: пути к сырым данным и артефактам модели.
- `training.yaml` — параметры препроцессинга (окна индикаторов) и гиперпараметры модели (RandomForest).
- `inference.yaml` — параметры инференса: настройки REST API и пороги принятия торговых решений.
- `.env.example` — **шаблон** переменных окружения (без значений секретов).

## Работа с секретами

- Реальный файл `.env` создаётся локально из `.env.example` и **не коммитится** (он добавлен в `.gitignore`).
- В репозитории должен находиться только `.env.example` с именами переменных.
