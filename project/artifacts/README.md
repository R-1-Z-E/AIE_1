# Артефакты проекта

В этой директории сохраняются сериализованные результаты обучения и визуализации экспериментов.

- `model.pkl` — сериализованная финальная модель (`RandomForestClassifier`), обученная на математических признаках (SMA, Volatility, Momentum). Файл служит "мозгом" для нашего REST API и полностью готов к инференсу.
- `figures/` — директория с сохраненными графиками (EDA и оценка моделей):
  - `price_trends...` — визуализация исторических трендов котировок актива.
  - `target_balan...` — график распределения классов целевой переменной (проверка на дисбаланс).
  - `baseline_eval...` — визуализация метрик базовой модели (baseline) для сравнения.
  - `final_model_...` — результаты оценки финальной обученной модели.

Чтобы сгенерировать файл модели с нуля или обновить её веса, выполните команду:

```bash
python -m src.models.train
```
