# Данные проекта

## Источник

В проекте используется **небольшой фрагмент открытого датасета** исторических финансовых котировок. 
Данные полностью деперсонализированы, не содержат конфиденциальной информации или реальных клиентских данных, что строго соответствует требованиям курса. 

Первичная выгрузка OHLCV (Open, High, Low, Close, Volume) получена через открытое API Binance (эндпоинт klines) для актива BTC-USDT.

## Файлы

- `trading_data.csv` — демонстрационная выборка (sample). Содержит менее 1000 строк и хранится в репозитории исключительно для обеспечения работы автоматических тестов (`pytest`) и удобства быстрой проверки проекта преподавателем без необходимости скачивать внешние базы.

## Схема признаков (сырые данные)

| Признак | Тип | Описание |
|---|---|---|
| `date` | str | дата торговой сессии |
| `open` | float | цена открытия актива |
| `high` | float | максимальная цена за день |
| `low` | float | минимальная цена за день |
| `close` | float | цена закрытия актива |
| `volume` | int / float | объем торгов за период |

*Примечание: Финальная целевая переменная (`target`) и технические индикаторы (`sma_7`, `sma_30`, `volatility`, `momentum_3d`) не хранятся в сыром файле, а генерируются динамически на этапе препроцессинга модулем `src.features.preprocess`.*
