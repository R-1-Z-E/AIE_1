# Тесты проекта

Набор модульных тестов на `pytest` для проверки работоспособности всех слоев:

- `test_data_loading.py` — проверка загрузки сырых котировок, валидация структуры датафрейма и обработка отсутствующих файлов.
- `test_preprocess.py` — математика признаков: расчет SMA, Volatility, Momentum, проверка удаления пустых значений (NaN) и бинарности таргета.
- `test_model_training.py` — проверка доступности оркестратора обучения и корректности импортов пайплайна.
- `test_api_service.py` — эндпоинты REST API (`/health`, `/predict`), автоматическая Pydantic-валидация входящих JSON-запросов.

## Запуск

```bash
cd project
pytest tests/
```
