# Исходный код проекта

Основной код проекта. Структура выстроена по слоям для обеспечения модульности и удобства тестирования:

- `data/` — слой работы с данными:
  - `loader.py` — загрузка исторических котировок из CSV-файлов и проверка их наличия.
- `features/` — слой препроцессинга:
  - `preprocess.py` — генерация технических индикаторов (SMA 7, SMA 30, Volatility, Momentum 3D) и разметка целевой переменной (target).
- `models/` — слой обучения и экспериментов:
  - `train.py` — оркестратор обучения: собирает данные, обучает финальную модель `RandomForestClassifier` и сохраняет её в артефакты.
- `service/` — REST API:
  - `app.py` — инициализация FastAPI, асинхронная загрузка модели и бизнес-логика эндпоинтов (`/health`, `/predict`).
  - `__main__.py` — точка входа для запуска сервиса через модуль (`python -m src.service`).
- `utils/` — инфраструктура:
  - `logging.py` — централизованная настройка форматирования и уровней логов для всего проекта.

## Точки входа

- `python -m src.models.train` — запуск пайплайна обучения и сериализация (сохранение) финальной модели.
- `python -m src.service` — запуск REST API сервиса локально.
