# Ноутбуки проекта

Экспериментальные ноутбуки. Основной код выносится в `src/`, а здесь проводится исследовательская часть, обучение и валидация моделей.

* `01_eda.ipynb` — загрузка исторических котировок через Binance API, генерация технических индикаторов (SMA, Volatility, Momentum), проверка баланса классов и визуализация трендов.
* `02_baselines.ipynb` — настройка MLflow, хронологическое разбиение данных (Time-based split) и обучение базовых моделей (DummyClassifier и LogisticRegression) для фиксации точки отсчета.
* `03_models_tuning.ipynb` — обучение нелинейного ансамбля (Random Forest), расчет доверительных интервалов метрик с помощью метода Bootstrap и сохранение финальной модели.

## Запуск

```bash
cd project
pip install -r requirements.txt
jupyter notebook
```
